# Vela One 设计系统页面设计说明

## 目标

新增独立的 `design-system.html`，把 Vela One 现有网站使用的颜色、字体、间距和常用组件整理为可查看、可复制、可在手机上阅读的设计说明书。它不替换或重排现有产品首页。

## 范围

- 新增独立页面：`design-system.html`。
- 新增该页面专用样式和行为文件：`design-system.css`、`design-system.js`。
- 将现有网站 `styles.css` 的 `--accent` 从 `#72b7ee` 改为 `#4a9edd`，使产品页与设计系统的强调色一致。
- 保持 `index.html` 的页面结构、产品图片、文案和导航不变。
- 不新增框架、构建工具、第三方库或后端。

## 页面结构

### 1. 顶部

- 标题为 `Design System`，副标题说明这是 Vela One 的设计规范。
- 右侧放置 44px 以上高度的明暗模式切换按钮。
- 首次打开时遵循系统明暗模式；用户点击后，选择写入 `localStorage`，下次打开仍保持手动选择。
- 切换按钮使用 `aria-pressed`、清晰文字和可见焦点样式，不依赖颜色单独传达状态。

### 2. 色彩系统

每个颜色卡片包含 100px × 100px 色块、名称、HEX、RGB、HSL、使用场景，以及其分别与白色和黑色的 WCAG 对比度。六种颜色和数据如下：

| Token | 色值 | RGB | HSL | 用途 | 对白色 | 对黑色 |
| --- | --- | --- | --- | --- | ---: | ---: |
| Ink | `#0B0E12` | `rgb(11, 14, 18)` | `hsl(214 24% 6%)` | 主文字、深色按钮 | 19.34:1 | 1.09:1 |
| Muted | `#66717A` | `rgb(102, 113, 122)` | `hsl(207 9% 44%)` | 次级文字、说明文字 | 4.99:1 | 4.21:1 |
| Ice | `#EDF1F3` | `rgb(237, 241, 243)` | `hsl(200 20% 94%)` | 浅灰银背景 | 1.14:1 | 18.48:1 |
| Graphite | `#0E1217` | `rgb(14, 18, 23)` | `hsl(213 24% 7%)` | 深色章节背景 | 18.79:1 | 1.12:1 |
| Accent | `#4A9EDD` | `rgb(74, 158, 221)` | `hsl(206 68% 58%)` | 强调、交互状态 | 2.91:1 | 7.23:1 |
| Paper | `#FBFCFC` | `rgb(251, 252, 252)` | `hsl(180 14% 99%)` | 页面背景 | 1.03:1 | 20.43:1 |

`Accent` 不使用白色小字；它统一搭配 `Ink` 文字，以获得 7.23:1 的对比度。卡片明确标注此使用规则。

### 3. 字体层级

展示四种实际页面文字样式：

| 名称 | CSS |
| --- | --- |
| H1 | `clamp(2.5rem, 8vw, 4rem)`, `font-weight: 800`, `line-height: 0.94` |
| H2 | `clamp(2rem, 6vw, 3rem)`, `font-weight: 700`, `line-height: 0.98` |
| Body | `1rem`, `font-weight: 400`, `line-height: 1.6` |
| Caption | `0.875rem`, `font-weight: 500`, `line-height: 1.4` |

每个示例显示样本文字与对应 CSS 值。大标题在窄屏中允许自然换行，避免横向溢出。

### 4. 间距系统

以 8px 为主基准，展示 `4px`、`8px`、`16px`、`24px`、`32px`、`48px`、`64px`、`96px`。每个项目显示带标签的实际尺寸条，条宽就是该像素值；96px 以下不会被缩放成抽象图示。

### 5. 组件库

- **按钮**：主要按钮、次要按钮、禁用按钮。主要按钮为深色底白字；次要按钮为透明背景和边框；悬停时有轻微上移或背景变化；禁用态不能点击。
- **卖点卡片**：一张大卡与一张小卡，包含标题、正文和色彩装饰。悬停或键盘焦点时显示轻微位移，焦点有可见轮廓。
- **导航**：同时展示展开与收起两种外观；收起状态提供至少 44px × 44px 的触摸按钮。
- 每个组件下方显示最小 HTML 使用示例。代码仅供复制，不执行。

## 技术设计

- `design-system.css` 中的 `:root` 使用 CSS Custom Properties 定义颜色、字体、间距、圆角、阴影和触摸尺寸 token。
- BEM 命名使用 `ds-` 前缀，例如 `.ds-color-card`、`.ds-color-card__swatch`、`.ds-button--primary`。该前缀避免与现有产品页 class 冲突。
- CSS 采用移动端优先：默认单列；宽度达到 720px 后，色彩和组件区域使用多列网格。
- `design-system.js` 只处理主题：读取系统偏好、读取/写入 `localStorage`、更新 `data-theme` 与无障碍标签。无额外依赖。

## 可访问性与体验

- 页面主背景和前景文字使用足够高的对比度；Accent 的白字限制会被明确展示。
- 所有交互元素至少 44px 高，支持鼠标、键盘和触屏。
- `:focus-visible` 有可见焦点样式。
- `prefers-reduced-motion` 会关闭卡片悬停位移和主题动画。
- 主题切换后颜色不只靠颜色区分，按钮文字和 `aria-pressed` 同时更新。

## 验收与测试

在 `tests/site.test.mjs` 中加入独立测试，验证：

1. 三个设计系统文件存在，HTML 引用了它们。
2. 六个 token 与 `#4A9EDD` 真实出现，现有 `styles.css` 的 Accent token 同步更新。
3. 四个字体层级、八个间距值、三类组件和示例代码都存在。
4. 主题控制具备 `prefers-color-scheme`、`localStorage`、`aria-pressed` 和 `data-theme`。
5. BEM 前缀、移动端媒体查询、焦点和减少动态规则存在。

手动检查 390px 和桌面宽度，确认没有横向滚动，主题切换能正常工作，禁用按钮不可操作。
