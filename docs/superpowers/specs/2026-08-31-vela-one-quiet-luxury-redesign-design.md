# Vela One「安静高级」视觉重构设计

## 1. 设计目标

将 Vela One 从“黑色耳机商品页”重构为一条完整的心理递进故事：

> 先被安静高级的产品吸引，再把自己代入它创造的生活，接着感受到功能带来的改变，最后通过技术证据相信它确实优秀。

首要记忆点仍然是通勤场景中的强降噪。舒适佩戴负责降低购买顾虑，音质、空间音频和续航负责增强价值感。

本轮借鉴 Apple 耳机页面的情绪节奏、产品聚焦和留白方式，也借鉴 NANFU 页面的大尺度舞台与强光影，但不复制其文案、图片、产品或红黑攻击性风格。

## 2. 核心判断

本轮不再使用网站现有女性，也不换成另一位有清晰身份的模特。

清晰人脸会让用户观看“她的故事”，同时与耳机争夺注意力；完全移除人体又会使页面缺少佩戴和操控证据。因此采用以下组合：

- 用产品和安静空间建立高级感。
- 用无人环境和生活物品制造自我代入。
- 只在佩戴、触控等必须说明身体关系的位置使用无身份的人体局部。
- 用声学结构、规格和认证完成可信证明。

不出现完整人脸，不塑造具体角色，不让任何人物成为页面主角。

## 3. 总体视觉语言

### 3.1 配色

- 主背景：深黑与石墨黑。
- 产品：冰银、冷灰、少量高光白。
- 强调：低饱和冷蓝，只用于光束、交互状态和声场。
- 生活场景：保留少量暖灰，防止画面过度冰冷。

禁止用大面积鲜红、霓虹彩色和持续发光效果制造刺激感。

### 3.2 光线

- 产品由窄幅顶光或侧后方轮廓光照亮。
- 背景大部分保持克制的暗部，不把所有细节同时展示。
- 技术章节提高明暗对比，让内部结构清楚，但不过度科幻化。

### 3.3 构图

- 每屏只设置一个主要视觉焦点。
- 标题与产品分区，移动端不得覆盖或贴近耳机。
- 留白不是空缺，而是表达安静和价值感的组成部分。
- 重要产品图使用大尺度，辅助物件数量保持在三件以内。

## 4. 页面心理递进与逐屏设计

### 第一屏：看见高级产品

**用户感受：** 这是一件值得靠近的高级产品。

- 黑色展厅作为背景。
- 冰银色耳机与充电盒作为唯一主角，像雕塑一样被冷光照亮。
- 标题与产品上下分区，不重叠。
- 文案保持简短，先说“世界安静下来”一类的结果，不先列规格。
- 动效只表现产品从暗处被光慢慢照亮，不持续漂浮或旋转。

### 第二屏：看见想拥有的生活

**用户感受：** 这个安静位置可以属于我。

- 使用空着的地铁座位、车窗与掠过的城市灯光。
- 耳机放在座位、扶手或极简桌面上，保持清晰。
- 只出现黑色笔记本、金属笔、通勤卡或极简包中的少量物品。
- 不出现完整人物，让空位成为用户进入画面的入口。

### 第三屏：感受到降噪改变

**用户感受：** 戴上它之后，通勤世界真的不同。

- “降噪开启”和“通透模式”必须使用同一机位、同一场景、同一产品位置。
- 降噪开启：背景声音对应的视觉线索退暗、模糊和远离，主体稳定。
- 通透模式：车厢轮廓、广播提示和环境方向重新清晰，整体仍保持克制。
- 手机端切换控件与完整场景处于同一视口，用户点击后能立即看见全部变化。
- 变化使用短暂过渡，不通过切换两张完全不同的海报制造假对比。

### 第四屏：理解声音品质

**用户感受：** 它不只是安静，声音本身也有层次。

- 使用现有耳机声学爆炸结构作为核心视觉证据。
- 先用听感标题说明低频力量、人声清晰与高频细节。
- 再解释双 DAC、11 mm 镀钛动圈、6.7 mm 微平板单元和 LHDC-V5。
- LHDC 与 Hi-Res Wireless 徽标进入统一的“认证与传输”信息带，不单独漂浮在页面角落。
- Dolby 内容作为空间娱乐体验，不抢占声学结构证明的位置。

### 第五屏：声音从四周展开

**用户感受：** 声音不再挤在耳边，而是在空间中展开。

- 不使用闭眼人物正脸。
- 耳机悬浮在暗色空间中央，以克制的环形声场和远近光层表达空间感。
- 环形元素的数量和透明度受到控制，避免成为装饰性噪声。
- 文案重点描述听感和场景，技术说明放在次级位置。

### 第六屏：证明佩戴自然

**用户感受：** 它能自然地成为身体的一部分。

- 使用耳朵、手指、肩颈或侧面剪影等无身份局部。
- 不显示完整人脸，不建立人物故事。
- 通过耳机与耳廓的贴合、手指触控和轻薄材质表现舒适与自然。
- 画面优先证明真实佩戴关系，避免只用羽毛、云朵等抽象隐喻。

### 第七屏：消除购买顾虑

**用户感受：** 我已经喜欢它，也没有明显理由拒绝它。

- 使用充电盒和耳机的清晰产品图。
- 集中呈现 8 小时单次聆听、降噪、重量、连接和关键规格。
- 数字少而明确，不让参数重新夺走前面建立的情绪。

### 结尾：完成拥有感

**用户感受：** 我想让这种安静进入自己的生活。

- 回到纯黑展厅和完整产品。
- 使用一句收束性文案，不重复全部卖点。
- 保留明确的下一步按钮，但不制造强迫感。

## 5. 视觉内容比例

- 70% 静默展厅：首屏、技术证明、结尾。
- 20% 无人通勤电影：生活代入和降噪模式切换。
- 10% 抽象声学艺术：空间音频和声音层次。

人体局部只作为功能证据，不计入人物叙事比例。

## 6. 素材策略

### 优先复用

- 现有冰银色耳机和充电盒产品图。
- 现有声学爆炸结构图。
- 现有 LHDC 与 Hi-Res Wireless 正式徽标。
- 已确认的产品规格和文案事实。

### 需要新增或重新制作

- 黑色展厅中的首屏产品主视觉。
- 同机位的降噪开启与通透模式环境素材。
- 无人通勤场景和少量生活物品素材。
- 不含人脸的佩戴与触控局部素材。
- 以耳机为中心的空间声场素材。

新素材不得改变耳机外形、颜色、结构比例或品牌识别。环境可以生成或合成，产品本体优先使用已有可靠素材。

## 7. 交互与动画

- 继续使用原生 CSS 与 JavaScript，不为视觉效果增加新框架。
- 页面进入动画以淡入、轻微位移和光线变化为主。
- 降噪模式切换是核心交互，必须提供明显但克制的状态反馈。
- 移动端不启用鼠标视差、持续 3D 漂浮或高负载 Canvas。
- 用户开启“减少动态效果”后，所有内容直接可见，核心交互仍可使用。
- JavaScript 加载失败时，正文和产品图不得隐藏。

## 8. 响应式原则

### 桌面端

- 允许使用接近满屏的大尺度舞台。
- 文案与产品可左右分区，但不能相互遮挡。
- 导航和已有锚点语义保持稳定。

### 手机端

- 文案区和产品区上下分离。
- 首屏不因追求满屏而裁掉耳机主体。
- 在 390 × 844 px 与 430 × 932 px 的 CSS 视口中，模式切换按钮、状态文案和场景核心主体必须同时可见，无须再次滚动。
- 卖点总览保持紧凑宫格，不退回连续单列海报。
- 390 px、430 px 以及 320 px 超小屏均不得产生横向溢出。
- 菜单顺序保持“概览、降噪、音质、佩戴、规格”，不恢复重复入口。

## 9. 技术范围

继续使用现有静态网站结构：

- `index.html`：调整章节内容与语义结构。
- `styles.css`：重构视觉系统和响应式布局。
- `script.js`：保留必要交互，调整降噪模式和轻量动画。
- `assets/`：加入经过确认的新视觉素材。
- `tests/site.test.mjs`：增加页面顺序、锚点、移动端布局、模式切换和资源存在性回归测试。

不增加 React、Vue、Next.js、数据库、支付、3D 框架或新的运行时依赖。

## 10. 验收标准

- 首屏第一焦点是 Vela One，而不是文字、人物或背景。
- 用户在前两屏能感受到“安静高级”和“我想进入这种生活”。
- 页面没有完整人物正脸，人体局部只用于佩戴和操作证明。
- 降噪与通透模式的差异在同一场景内清楚可见。
- 技术章节能准确说明双 DAC、双单元、LHDC-V5 与认证信息，且没有重复文案。
- 手机端文案不遮挡耳机，切换模式时能看见完整主要场景。
- 所有导航卡片进入对应内容，而不是上一章节。
- 页面关闭 JavaScript 后仍可阅读主要内容。
- 开启减少动态效果后没有持续动画。
- 自动化测试通过，`git diff --check` 无错误。
- Cloudflare Pages 部署后匿名访问正常，真实 DOM、图片资源、菜单、锚点和模式切换均经过在线验证。

## 11. 明确不做

- 不用另一个完整模特替换现有女性。
- 不复制 Apple 或 NANFU 的图片、产品、文案和页面代码。
- 不通过大量粒子、霓虹、红色或持续动画制造虚假的视觉冲击。
- 不虚构产品规格、实验数据或认证。
- 不在本轮增加购买、账户、支付和后台功能。
